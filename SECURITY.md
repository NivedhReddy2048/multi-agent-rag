# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within EKIP, please send an email to `security@ekip.edu`. All security vulnerabilities will be promptly addressed.

EKIP includes built-in security protections against Prompt Injection attacks, HTML sanitization, and API key masking in `core/security/`.
